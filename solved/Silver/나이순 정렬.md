```c++
#include <iostream>
#include <string>
#include <map>
using namespace std;

int main()	
{
	multimap<int, string> mp;
	int size;
	int age;
	string name;

	cin >> size;
	for (int i = 0; i < size; i++)
	{
		cin >> age >> name;
		mp.insert({age, name});
	}

	for (int i = 1; i <= 200; i++)
	{
		for (multimap<int, string>::iterator iter = mp.lower_bound(i); iter != mp.upper_bound(i); iter++)
		{
			cout << iter->first << " " << iter->second << endl;
		}
	}
}
```
### [10814] 나이순 정렬
1. 중복이 가능하며, 나이가 같다면 먼저 입력한 순서로 출력한다.
2. multimap에서 반복자를 가져올때 해당 key의 중복 데이터는 가져올 수 없다.
3. 고로 아래 두 반복자를 사용해서 반복 순회를 해주었다.
   <br>->  ```lower_bound(const Key& key)``` : key에 해당하는 맨 첫번째 원소를 가리키는 반복자를 반환
   <br>->  ```upper_bound(const Key& key)``` : key에 해당하는 맨 마지막 원소의 다름을 가리키는 반복자를 반환
