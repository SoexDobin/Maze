```c++
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int N;
    cin >> N;

    vector<pair<int, int>> points(N);

    for (int i = 0; i < N; i++) {
        cin >> points[i].first >> points[i].second;
    }

    // 정렬: x 오름차순, x가 같으면 y 오름차순
    sort(points.begin(), points.end());

    for (const auto& p : points) {
        cout << p.first << " " << p.second << "\n";
    }

    return 0;
}
```
### [11650] 좌표 정렬하기
1. sort() 함수는 pair객체에 대해 ```first``` 오름차순 정렬을 하며 저장한다.
2. 핵심은 ```first```가 같다면 ```second```를 통해 한번더 비교해서 계산한다는 것이다.
3. 복잡도는 ```100000 log_2 100000 = 100000 x 16.6 = 1660000```이다
